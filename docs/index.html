Invoice extraction agent — measured against a baseline

Personal project
Problem
A bookkeeper receives a few hundred supplier invoices a month and retypes them into a spreadsheet. The cost is not the typing, it is the errors nobody catches.
What I built
An agent that reads a PDF, extracts twelve fields, checks them against business rules, and sends back for human review the fields it could not read with certainty. Ships with a regex baseline on the same test set, so the result is a comparison, not a claim.
Decisions
The tool loop is written by hand — no framework — so every step is explainable. The schema rejects incoherent totals (excl. tax + VAT must equal the total) and returns the error to the model, which re-reads the document instead of guessing. The test set has four invoice templates, because one template flatters every approach.
Result
97 % field accuracy, 7 of 8 documents perfect, against 22 % for the regex baseline. One silent failure on an ambiguous US date is documented in the README rather than hidden — that failure is what the next iteration fixes.

Video factory — one command, finished video

Personal project
Problem
Publishing two videos a week means four hours each of scripting, voice-over, editing and subtitles. Most of that time is mechanical, not creative.
What I built
A command line tool that takes a topic and produces the finished piece: script, voice-over, generated visuals, word-level subtitles, edited MP4, thumbnail and metadata. Each step is resumable, so a failure costs one step instead of the whole run.
Decisions
Visuals are generated locally — no stock footage, no licensing questions. Subtitles are burned in as image overlays because the ffmpeg build on this machine ships without libass; finding that out took an hour, and working around it took twenty minutes.
Result
A 75-second pilot renders in about a minute on a laptop, with no paid service called. The output is watchable but generic — the human part still has to be added by hand, which is honest and is exactly what I tell clients.
